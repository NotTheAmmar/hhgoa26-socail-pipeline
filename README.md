# Face ID & Blockchain Verification Pipeline

> **HH Goa 2026 · Task 3**

An end-to-end pipeline that:
1. **Detects a face** in an uploaded photo
2. **Reverse-image-searches** the face across the web and social media (via Google Lens)
3. **Stores a tamper-evident hash** of the discovered content on a local Ethereum blockchain
4. **Re-verifies** the hash on-chain to prove the record hasn't been altered

```
📸 Face scan → 🔍 Google Lens (web/social) → ⛓️ Hardhat EVM → ✅ On-chain verify
```

| Component | Technology |

| Web UI | Flask + vanilla HTML/JS |

All free tiers — no credit card required anywhere.

## Prerequisites

### System
- **Python 3.10–3.12** (required — `dlib`/`face_recognition` have no pre-built wheels for 3.13+; use `python3.12 -m venv .venv`)
- Node.js 18+ & npm
- `cmake` and `dlib` build tools (for `face_recognition`):

  ```bash
  # Ubuntu / Debian
  sudo apt install build-essential cmake libopenblas-dev liblapack-dev

  # macOS
  brew install cmake
  ```

### API Keys (free)
1. **SerpAPI** — [serpapi.com](https://serpapi.com/) → 250 free searches/month
2. **imgbb** — [imgbb.com/api](https://imgbb.com/api) → free, no limits stated

## Setup

### 1. Clone & configure environment

```bash
git clone https://github.com/NotTheAmmar/hhgoa26-socail-pipeline.git
cd hhgoa26-socail-pipeline

cp .env.example .env
# Edit .env and fill in SERPAPI_KEY and IMGBB_API_KEY
```

### 2. Python dependencies

```bash
python3.12 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

pip install -r requirements.txt
```

> ⚠️ `face-recognition` compiles dlib from source on first install — this takes a few minutes.

### 3. Blockchain setup (Hardhat)

```bash
cd blockchain
npm install
```

---

## Running the Pipeline

You need **three terminal windows**:

### Terminal 1 — Start the local Ethereum node

```bash
cd blockchain
npx hardhat node
```

Keep this running. It prints 20 pre-funded accounts with their private keys.

### Terminal 2 — Deploy the smart contract

```bash
cd blockchain
npm run deploy
```

This compiles `ContentVerifier.sol`, deploys it to the local node, and writes `pipeline/contract_config.json` with the contract address and ABI for Python to use.

### Terminal 3 — Start the web app

```bash
# From the project root
source .venv/bin/activate
python app.py
```

Open **http://localhost:5000** in your browser, upload a face photo, and click **Run Pipeline**.

## Smart Contract

**`ContentVerifier.sol`** — deployed on the local Hardhat EVM.

```solidity
function storeRecord(bytes32 contentHash, string url, string title) external;
function verifyRecord(bytes32 contentHash) external view
    returns (bool exists, string url, string title, uint256 timestamp);
```

The `contentHash` is a SHA-256 digest of the discovered post's metadata (URL, title, source, similarity score, timestamp). Once stored, it cannot be modified — any tampering would produce a different hash that fails `verifyRecord()`.

**Blockchain used:** Hardhat Network (local EVM simulation — `http://127.0.0.1:8545`).  
No testnet ETH or wallet setup required.

## Known Limitations

- **Local blockchain only** — the Hardhat node resets on restart; re-run `npm run deploy` after a restart.
- **SerpAPI rate limit** — 250 searches/month on the free tier. More than enough for a demo.
- **Face similarity on thumbnails** — thumbnail images from Google Lens are often small/cropped; similarity scores may be low even for genuine matches. The raw search results are still valid.
- **imgbb hosting** — uploaded face images are publicly accessible (but ephemeral for demo purposes). Do not upload sensitive photos.
- **dlib compile time** — first `pip install` can take 5–10 minutes on slower machines.
- **Single-face assumption** — when multiple faces are detected, the largest face is selected.
